Getting started

How to Use the API

Follow these steps to run the backend locally.

01

Clone the Repository

Download the backend source code from GitHub.


git clone YOUR_GITHUB_REPOSITORY_URL
02

Install Dependencies

Navigate to the project directory and install packages.


npm install
03

Configure Environment Variables

Create a .env file and configure MongoDB, JWT, Cloudinary and Gemini credentials.


MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret
04

Start the Server

Run the backend using your configured npm script.


npm run dev
05

Explore the API

Open Swagger documentation to explore endpoints, provide authentication credentials and test requests.


Open /api-docs ↗
